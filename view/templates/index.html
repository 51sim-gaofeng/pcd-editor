Static PCD files

        
Use File → Open PCD File… or Open Directory… (also available in the sidebar File section) to load .pcd files. ASCII, binary, and binary_compressed formats are all supported, with disk caching for fast reloads.

        
    
          
  • Playback: seek bar, FPS slider, ←/→ step, Space play/pause.
    • 
          
  • View: 3D / Top / Front / Left presets, Free-fly camera (F), point size, color mode (height / intensity / flat), axis flip.
    • 
          
  • Filter Z: keep or exclude a height range.
    • 
          
  • Grid: square or circular ground grid with configurable size, step, and coordinate labels.
    • 
          
  • Edit Cloud: Pick / Lasso / Eraser to select points, then Delete, Undo, or Save PCD.
    • 
          
  • Trajectory: Draw waypoints on the cloud, then Export / Import / Save to server.
    • 
        

        
Streaming Lidar Receiver

        
Real-time Velodyne-style MSOP/DIFOP UDP ingestion with multi-threaded decode (separate network I/O and decode threads). Set the bind IP/port and DIFOP info port, then click Streaming Live to start. Use Max pts and Render FPS sliders to trade off density vs. smoothness; Space pauses rendering without stopping reception.

        
DDS Live

        
Live UDP point cloud over a compact binary protocol, pushed to the browser via WebSocket. Auto-detects unicast / broadcast / multicast based on the IP you enter. Adaptive max-points budget automatically downsamples under load and ramps back up when headroom returns. Tri-state control: DDS Live / Pause / Stop.

      

      

        
Camera Receiver (GVSP/JPEG over UDP)

        
Switch to the 📷 Camera tab, set Bind IP and Port, then click Connect to start receiving JPEG frames over UDP.

        
    
          
  • Frames are pulled via long-poll (/api/camera_frame) using an incrementing frame id, so only new frames are transferred.
    • 
          
  • Show FPS badge toggles an on-screen overlay with the live receive rate.
    • 
          
  • Status text shows the current receiver state, resolution, and latest frame metadata.
    • 
          
  • Camera mode is mutually exclusive with DDS Live to avoid receiver/resource conflicts — switching to Camera stops any active DDS session.
    • 
        

      

      

        
Gaussian Splatting (3DGS / PLY)

        
Switch to the 🎃 3DGS tab. Use File → Open PLY (3DGS)… or pick a file from the GS File dropdown to load a .ply scene.

        
    
          
  • SH Level: switch spherical-harmonics degree (0–3) to balance quality vs. performance.
    • 
          
  • Model Rotation: adjust Roll / Pitch / Yaw in degrees; changes apply immediately. Double-click inside the viewport to set the rotation pivot for more natural interactive alignment.
    • 
          
  • Color Adjust: tune Brightness / Contrast / Saturation / Temperature / Hue in real time, with a one-click Reset.
    • 
          
  • The status area under the panel shows loading state, load time, splat count, and live FPS.
    •
